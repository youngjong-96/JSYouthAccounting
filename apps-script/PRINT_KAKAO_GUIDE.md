# 인쇄·카카오톡 보고서 자료 사용 안내

`메일발송` 탭에서 선택한 행을 기준으로 인쇄용 PDF와 카카오톡용 PNG를 함께 만듭니다. 같은 창에서 모든 PNG 다운로드와 실제 메일 발송을 한 번에 실행할 수도 있습니다.

## 자료 만들기

1. `메일발송` 탭에서 사용할 행의 `발송일`을 확인합니다.
2. `보고서종류`를 `주간`, `월간`, `주간+월간` 중에서 선택합니다.
3. 해당 행의 `발송선택` 체크박스 하나만 선택합니다.
4. 상단에서 `📧 회계보고 > 인쇄·카톡 자료 만들기`를 실행합니다.
5. 보고서 생성과 PNG 변환이 끝날 때까지 창을 닫지 않습니다.

보고서에 `#N/A`, `#REF!`, `#VALUE!` 등의 수식 오류가 있으면 자료 생성을 중단합니다. 시트 수식을 수정한 뒤 다시 실행합니다.

## 자료 만들고 메일 발송하기

미리보기가 모두 나타난 뒤 `자료 만들고 메일 발송하기` 버튼을 누릅니다.

1. 확인창에서 발송 기준일, 보고서 종류, 받는 사람 수, 참조 수, 제목을 확인합니다.
2. `확인`을 누르면 모든 PNG 다운로드를 먼저 시작합니다.
3. 이어서 선택 행의 실제 수신자와 참조 주소로 메일을 발송합니다.
4. 화면에 `메일 발송을 완료했습니다`가 표시될 때까지 창을 닫지 않습니다.

이 버튼은 테스트 발송이 아니라 **실제 발송**입니다. 기존 중복 발송 방지가 적용되므로 `성공여부`가 이미 `실제 성공`인 행은 다시 발송할 수 없습니다. 성공하면 `발송선택` 체크박스가 자동으로 해제됩니다.

브라우저에서 여러 파일 다운로드 허용을 요청하면 허용합니다. PNG 다운로드가 시작된 뒤 메일 발송만 실패한 경우에는 저장된 PNG는 그대로 사용하고, 오류를 수정한 뒤 기존 `실제 발송` 또는 자료 창의 결합 버튼을 다시 실행합니다.

## 인쇄하기

각 보고서의 `PDF 열기·인쇄` 버튼을 누르면 새 탭에서 PDF가 열립니다. PDF 화면의 인쇄 버튼 또는 `Ctrl+P`를 사용하여 인쇄합니다.

- 주간보고가 한 페이지를 넘으면 PDF가 자동으로 여러 페이지가 됩니다.
- 월간보고도 PDF에 계산된 모든 페이지가 포함됩니다.
- 인쇄 전에 프린터, 용지 방향, 부수 및 페이지 수를 확인합니다.

## 카카오톡용 PNG 받기

다운로드 창에는 PDF의 각 페이지가 미리보기로 나타납니다.

- 한 페이지 보고서: PDF 파일명과 같은 PNG 1개
- 여러 페이지 보고서: 파일명 끝에 `_1`, `_2`가 붙은 PNG 여러 개

각 페이지의 `PNG 다운로드`를 누르거나 상단의 `모든 PNG 다운로드`를 사용합니다. 다운로드된 PNG를 번호 순서대로 카카오톡 대화방에 끌어다 놓아 전달합니다.

## 파일명 예시

```text
2026-08-23_청년부_주간보고.pdf
2026-08-23_청년부_주간보고.png
2026-08-23_청년부_월간보고.pdf
2026-08-23_청년부_월간보고_1.png
2026-08-23_청년부_월간보고_2.png
```

## 주의사항

- `모든 PDF 다운로드`와 `모든 PNG 다운로드`는 메일을 발송하지 않습니다.
- 메일도 함께 보내려는 경우에만 `자료 만들고 메일 발송하기`를 사용합니다.
- 자료만 다운로드하면 `발송선택` 체크박스는 자동으로 해제되지 않습니다.
- 보고서 생성이 끝나면 주간·월간보고서의 기존 선택값으로 자동 복원됩니다.
- PNG 변환 도구는 고정 버전의 Mozilla PDF.js를 HTTPS로 불러오며, PDF 내부 스크립트 실행은 비활성화되어 있습니다.
- 다운로드 위치는 브라우저 설정을 따릅니다. 일반적으로 Windows의 `다운로드` 폴더에 저장됩니다.
