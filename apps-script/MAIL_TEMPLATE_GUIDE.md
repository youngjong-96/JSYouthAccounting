# 메일 제목·본문 작성 안내

이 안내서는 Google Sheets의 `메일발송` 탭을 사용하는 모든 사용자를 위한 문서입니다.

## 기본 사용법

메일을 보낼 때 Apps Script는 `발송선택`이 체크된 행의 정보를 읽습니다.

- `발송일`: 보고서의 연도·월·주차와 날짜 치환 기준
- `발송메일`: 실행 중인 Google 계정 확인 및 답장받을 주소
- `수신자1`, `수신자2` 등: 실제 메일의 받는 사람
- `참조1`, `참조2` 등: 실제 메일의 참조
- `메일제목`: 발송할 제목
- `메일본문`: 발송할 본문
- `보고서종류`: `주간`, `월간`, `주간+월간`
- `발송선택`: 이번에 발송할 행 하나를 선택
- `성공여부`: 처리 중·성공·실패 결과가 자동 기록됨

열 순서는 자유롭게 바꿀 수 있지만 헤더와 각 열의 데이터는 열 전체로 함께 이동해야 합니다. 스크립트는 상단 1~5행에서 헤더 행을 자동으로 찾으며, 현재처럼 헤더가 1행이면 데이터는 2행부터 읽습니다.

## 제목과 본문에서 사용할 수 있는 치환자

다음 치환자는 `메일제목`과 `메일본문`에서 모두 사용할 수 있습니다.

| 치환자 | 결과 예시 |
|---|---|
| `{발송일}` | `2026년 8월 23일` |
| `{발송일ISO}` | `2026-08-23` |
| `{연도}` | `2026` |
| `{월}` | `8` |
| `{주차}` | `4주차` |

`발송일`은 실제 메일 전송 시각이 아니라 보고서를 계산하는 기준일입니다.

## 본문에 보고서 넣기

다음 치환자는 `메일본문`에서 사용합니다.

- 주간보고: `{주간보고}`, `{주간보고 캡처 이미지}`, `{주간보고 캡쳐 이미지}`
- 월간보고: `{월간보고}`, `{월간보고 캡처 이미지}`, `{월간보고 캡쳐 이미지}`

치환자 이름에 “이미지”가 있어도 PNG 파일을 넣는 기능은 아닙니다. HTML 메일 본문에는 보고서 표가 들어가고, 동일한 보고서가 PDF로 첨부됩니다.

선택한 보고서의 치환자를 본문에 쓰지 않아도 보고서 표는 본문 마지막에 자동으로 추가됩니다. 보고서 치환자는 메일 제목에는 사용하지 않습니다.

## 작성 예시

메일제목:

```text
[{주차}] {발송일} 청년부 회계보고
```

메일본문:

```text
안녕하세요.

{발송일} 기준 청년부 {주차} 회계보고입니다.

{주간보고}

자세한 내용은 첨부된 PDF와 Excel 파일을 확인해 주세요.
감사합니다.
```

## 테스트 발송과 실제 발송

- 테스트 발송은 `수신자`와 `참조`를 사용하지 않고 `발송메일` 주소 한 곳으로만 보냅니다.
- 테스트 메일 제목에는 `[테스트]`가 자동으로 붙습니다.
- 실제 발송은 모든 `수신자`와 `참조` 주소를 사용합니다.
- 실제 성공한 행은 중복 발송 방지를 위해 다시 발송할 수 없습니다.
- 실제 발송 전에는 반드시 같은 행으로 테스트 발송하여 제목, 본문, 보고서 및 첨부파일을 확인합니다.

## 발송메일 주의사항

`발송메일`에 임의의 주소를 입력하여 발신자를 바꿀 수는 없습니다. 이 주소는 Apps Script를 실행하는 Google 계정과 같아야 하며, 메일의 답장받을 주소로도 사용됩니다. 실제 발송 계정은 스크립트를 실행한 Google 계정입니다.

시트 상단의 `📧 회계보고 > 메일 제목/본문 작성 안내`에서도 핵심 사용법을 확인할 수 있습니다.
